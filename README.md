Seangroup — Интернет-магазин на ASP.NET Core MVC

Полнофункциональная веб-платформа для продажи товаров или услуг с системой управления заказами, корзиной, авторизацией и панелью администратора.

 О проекте
Seangroup — это интернет-магазин, разработанный на базе ASP.NET Core MVC. Проект реализует полный цикл электронной коммерции: 
от просмотра каталога до оформления заказа и приёма платежей.

В проекте реализованы:
Каталог товаров/услуг с детальными страницами.
Корзина покупок с возможностью добавления, удаления и изменения количества товаров.
Оформление заказа с выбором способа оплаты.
Система аутентификации и авторизации (регистрация, вход, роли пользователей).
Личный кабинет для просмотра истории заказов.
Административная панель для управления товарами, заказами и пользователями.

Технологии
Платформа: ASP.NET Core MVC (.NET 8)
Язык: C#
ORM: Entity Framework Core
База данных: SQL Server 
Аутентификация: ASP.NET Core Identity
Фронтенд: HTML, CSS, JavaScript, Bootstrap
Управление версиями: Git, GitHub

Проект построен по классической архитектуре MVC
